# 0.8 本地功能预览

本轮围绕“迁移后引用丢失”重做工作流程。先保护文件和旧路径，再诊断需要改写的引用；跨身份恢复通过新方案显式导入。尚未提交或发布，也未迁移本机真实用户数据。

## 已实现流程

- 环境清单：独立新建/打开方案，添加、编辑、移除草稿，筛选和完整勾选范围，保存/载入草稿，后台任务完成后保留未执行编辑。
- 执行前检查：按项目聚合错误和提醒，估算复制量和卷空间，检查路径、链接、状态与历史副本冲突；预检不创建目录或锁。
- 核心迁移：严格方案结构和阶段校验，Apply 整批预验证，Resume 拒绝未完成/失配副本，撤销使用校验后的暂存目录与恢复 journal；新出现的原位置内容另行保留。
- 引用诊断：选定目录、完整目录前缀映射、JSON/快捷方式路径识别、文本格式诊断和虚拟环境重建提示。扫描报告经当前 Windows 用户保护，修复时验证报告和文件是否变化。
- 支持的引用修复：JSON 字符串值，快捷方式目标与工作目录；备份后替换，不执行脚本或程序。
- 重装导入：导出完成状态的恢复清单，映射旧用户和数据位置，只读预检后创建当前用户的新方案；另行预检重连，不绕过旧方案 SID 限制。
- 新界面：明亮侧栏、环境清单、引用诊断、重连与恢复、操作记录、帮助以及确认执行页面；嵌套操作控件统一冻结，后台阶段/百分比反馈。

## 验证方式

`Core.Tests.ps1` 使用临时目录验证迁移、重复操作、换位置、恢复、撤销、SHA-256 与空目录比较、锁、非法状态、路径冲突及恢复 journal 的中断点。

`Preflight.Tests.ps1` 覆盖多项 JSON、零写入预检、目标离线、阶段及来源状态、重叠/历史副本/保留路径、链接、空间估算和受限扫描。

`Environment.Tests.ps1` 覆盖路径映射、敏感字段跳过、JSON 与快捷方式修复备份、文件变化和报告篡改拒绝、恢复清单、显式用户/磁盘映射与零写入预览。

`Ui.Tests.ps1` 在真实 WinForms 控件和事件循环内验证草稿往返、失败打开保持上下文、筛选选择、后台预检/迁移、两个独立 Worker 间的扫描/修复、导出/导入/重连、隔离登录入口、嵌套忙碌门控及三种窗口尺寸。截图使用 Demo 路径，属于离屏渲染，不代表真人验收。

最终包中的 EXE 会再次运行嵌入引擎自测与界面集成测试；准确计数、哈希和限制保存在 `releases/verification-0.8.0-preview.1.json`。

## 尚未覆盖

真实重装/还原周期、物理多磁盘、ACL/企业策略差异、多显示器高 DPI、用户日常软件启动与业务工作流仍需目标机器验证。注册表、PATH、服务/驱动、应用安装器、凭据与授权、二进制配置/数据库专用迁移不在自动修复范围。

恢复清单中的数量与字节摘要只用于基本一致性检查，不能证明文件内容未改变。JSON 修复只支持能够无歧义解码的文件；修改前的原始文件备份应保留。路径兼容与引用诊断也不能证明某个安装型软件可直接跨系统运行。
