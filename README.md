## 从重置电脑，到熟悉的环境

Windows 10 中文免安装工具。将桌面文件、文档、下载和指定软件配置保存到不会被还原的 NTFS 固定磁盘，并在原位置建立目录联接。需要 Windows 自带的 PowerShell 5.1 和 Robocopy，无需安装第三方依赖。

## 你可以做什么

- 支持全选、取消全选，以及让全部勾选项目跟随默认路径。
- 目标列显示实际路径；统一根目录下按名称和短标识分开保存，避免同名软件混在一起。
- 已迁移项目可直接换位置：校验新副本后切换连接，旧数据保留；不必先复制回 C 盘。
- 原创锚点图标、圆角卡片和按钮、勾选计数、键盘焦点反馈，以及可调整大小的窗口。
- 后台复制与校验、阶段进度、项目连接状态、按勾选项撤销以及操作日志。

- 双击 EXE 直接进入中文界面；引擎和界面内置在同一个文件中，无需旁边放置 PS1 或 CMD。
- 使用 Windows GUI 程序入口，客户端不附加控制台，Robocopy 复制过程也不创建窗口。
- 深色侧栏、浅色卡片、清晰的主按钮和目标目录列表。
- 原有自选磁盘、逐项指定位置、校验、备份、重新连接和撤销流程保留。可读取 0.1.0～0.4.0 方案。
- 便携包包含客户端和图文说明；也可以只使用单个 EXE。源码与构建脚本保留在项目中。运行依赖 Windows 10 自带的 .NET Framework 和 Windows PowerShell 5.1，不需要安装 PowerShell 7。

## 使用

1. 将工具解压到不会还原的磁盘，双击 `EnvAnchor.exe`。默认保存目录另选一个空文件夹，例如 `E:\个人环境` 或 `F:\个人环境`，不要选工具所在文件夹。该位置保存方案和默认数据；支持系统盘以外的固定 NTFS 磁盘，不再限定 E 盘及以后盘符。
2. 先关闭 Clash 等相关软件，勾选需要保留的目录。通过「添加软件配置」选择客户端实际使用的配置目录；请在客户端中查看，不要仅选择软件安装目录，也不要选择整个 AppData。
3. 点击「全选」，修改顶部默认保存位置，再点击「勾选项统一用默认路径」。每个项目会显示自己的子文件夹，例如 `F:\个人环境\桌面文件-短标识`。也可选中一行，通过「修改单项目标」单独设置位置。
4. 检查目标预览，点击「统一迁移勾选项」。工具先检查所有选中项目的路径，再复制并逐文件校验 SHA-256，保留原文件夹为同级备份，然后建立联接。目标子目录须为空或尚未创建，项目之间不能共享或嵌套路径。失败时查看窗口中的原因，不要自行删除备份。
5. 系统还原后，通过「打开已有方案」选择原来包含 `state.json` 的目录，点击「重置后重新连接」。工具读取方案中的各项目目标，不使用列表中新选择的位置。还原生成的旧目录会另行备份，不覆盖持久磁盘数据。所有相关磁盘均需连接且盘符不变。
6. 如需自动执行，勾选「登录时自动重新连接」，执行迁移或重新挂接，并由管理员将 Windows 登录启动项保存进还原基线。仅在保留盘保存脚本不能使已还原的系统自动运行它。登录挂接与软件自启动之间没有顺序保证，请在挂接完成后启动软件。

## 修改已有方案的磁盘

点击「打开已有方案」选择原方案目录 → 全选 → 修改顶部默认路径 →「勾选项统一用默认路径」→「统一迁移勾选项」。只改文本或目标预览不会移动文件；必须点击迁移。

文件数据迁移到新位置，方案清单和登录入口仍保留在原方案目录，因此原方案磁盘也需要保留。重新打开客户端时仍选择原方案目录。旧数据副本不会自动删除；目标复制未完成时原连接继续有效，已完成复制但连接切换中断时可点击「重置后重新连接」恢复。

新版本可读取 0.1.0～0.3.0 的方案；如果旧版已设置自动入口，用新版在原方案位置勾选自动入口并执行重新连接，可更新保留盘内的工具副本。已开始换位置的方案请使用本版完成恢复。

## 撤销和数据保护

「撤销勾选项目」只将选中项目的最新内容复制回原目录，保留持久副本和历史备份。其他项目保持连接；全部撤销后才移除本方案的登录入口。复制途中失败可再次撤销。C 盘仍受还原保护时，复制回去的数据下次开机仍可能被还原。

「保存登录设置」可单独启用或停用当前方案的登录入口，不必再执行文件迁移。当前启动入口一次关联一个方案，仍需管理员将它保存进还原基线。

复制和校验在后台运行。操作期间可以移动窗口，不能重复提交或关闭窗口；完成后恢复操作。方案目录内的 `operations.log` 记录结果与失败原因，不包含文件正文。多个窗口同时处理同一方案时，只允许一个任务执行。

方案 `state.json` 存在保存位置，只适用于原 Windows 用户 SID。重装系统或更换用户后不自动复用。不要手工修改方案路径。原位置的 `*.env-anchor-backup-*` 是备份，确认数据完整后由用户决定是否清理。工具不会自动删除它们；迁移时原盘暂不释放空间。

支持非系统盘的固定 NTFS 卷，请自行确认不会还原且盘符固定。拒绝含嵌套链接、OneDrive 云占位文件的目录。目标磁盘不可用时停止恢复或撤销，不先移除原联接。文件被占用、权限不足、空间不足时会停止；不要用其他管理员账户运行来替代原用户。数据量较大时校验耗时较长，请勿强制结束客户端。

## 范围

- 保存的是桌面文件，不包括图标排列、任务栏、主题或所有 Windows 设置。
- 软件本身也应放在保留盘或系统还原基线中；本工具只迁移所选配置，不安装软件。
- Clash 客户端名称和配置目录由用户选择，不猜测订阅路径、不读取或上传订阅内容。系统代理开关、TUN 服务/驱动仍由客户端管理。
- 不迁移浏览器凭据、账户身份或整套用户目录；不能保证与 Windows 加密身份绑定的数据跨系统可用。
- 默认不修改当前系统。启动界面仅查看常用目录；点击操作按钮后才写入。

## 开发验证

构建机需要 Python 和 Pillow（`python -m pip install Pillow`）。运行客户端不需要 Python。设计源文件见 [SVG 图标](assets/app.svg)，完整版本记录见 [CHANGELOG.md](CHANGELOG.md)。

执行 `python build.py` 使用系统 .NET Framework C# 编译器构建内嵌脚本的 Windows GUI EXE，并对最终 ZIP 解压后的单文件客户端运行验证。检查 PE GUI 子系统、运行时无控制台、49 项合成目录测试、全选/取消全选、默认路径预览、后台任务与消息循环、方案切换、隔离目录中的登录快捷方式和界面渲染。未更改真实用户配置、系统启动入口或代理。未完成真实关机还原和多显示器高 DPI 测试。

执行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File tests\Core.Tests.ps1` 使用临时合成目录测试复制、挂接、模拟系统还原、再次挂接、撤销和链接拒绝。

执行 `powershell.exe -NoProfile -STA -ExecutionPolicy Bypass -File EnvAnchor.ps1 -SmokeTest` 检查窗体及事件构建，不显示窗口、不修改用户设置。

本地验证不能代替目标电脑的真实关机还原测试。首次部署建议先用无重要数据的测试文件夹验证一个还原周期。
